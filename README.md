## 认知卡片标准格式（8个必填字段）

1. **核心法则**：一句话结论，「条件+动作+边界」，≤35字
2. **详细解释**：机制+反例/风险+边界，2-3句
3. **真实案例或数据支撑**：案例=人物+时间+困境+行动+结果；原则=数据口径+关键对比+结论
4. **行动建议**：分「做什么/不做什么」，动词开头
5. **使用配方**：什么时候用/怎么调用/输出什么格式/搭配哪些卡片
6. **关联周期**：债务/产业/人口/政策/美元/康波，标注阶段
7. **优先级**：P0直接影响资金安全/P1重要参考/P2背景知识
8. **来源和置信度**：高=官方一手可交叉验证/中=单一可信二手/低=推测

**核心字段是「使用配方」**——不只是「这是什么」，而是「什么时候用、怎么用、和什么搭配用」。

## 金融翻译系统

输入金融文本→输出：
- 大白话翻译（≤400字）
- 周期定位（涉及哪些周期、什么阶段）
- 对普通人的影响
- 观察信号（接下来看什么数据验证）

v0.3架构：先判断再翻译两层结构
- **判断层（judger.py）**：纯规则脚本，28条正则概念匹配+关键词评分，输出文本类型/涉及周期/利好利空/置信度
- **翻译层（translator_v03.py）**：把判断结果作为上下文做深度翻译

测试评分：v0.2 CPI数据 8.5/10，v0.3降准新闻 质量很高
